# GRKit

RICOH GR III および GR III HDF ファームウェア 2.10 専用です。

## インストール

1. カメラの電源を切ります。
2. `SD_ROOT` の中身を メモリーカードのルートにコピーします。
3. カードを入れます。MENU ボタンを押したまま電源を入れます。カメラの電源が自動で切れるまで待ちます。
4. 通常どおり電源を入れます。

手順 3 で、カメラの SD スクリプトがオンになります。カメラに Mode Set Command、続いて Complete が表示され、その後電源が自動で切れます。

![Mode Set Command の画面に Script - Enable と Complete が表示されています。](images/modeset.png)

SD スクリプトがすでにオンの場合は、手順 3 を省略します。
インストール後は、カードのルートから `00078350.588` と `DEVELOP.MOD` を削除できます。この手順は任意です。

## アップデート

1. カメラの電源を切ります。
2. 新しいパッケージの `SD_ROOT` の中身を SD カードのルートにコピーします。既存のファイルは置き換えても統合してもかまいません。
3. カメラを通常どおり起動します。

GRKit は設定とエフェクトを `GRKIT` フォルダーに保存するので、アップデート後も残ります。先に `SCRIPT` を削除する必要はありません。GRKit 1.2 以前からアップデートするときに `SCRIPT` フォルダーを置き換えると（macOS の Finder の標準の「置き換える」など）、それまでの設定と、新しいパッケージにないエフェクトは失われます。GRKit 1.2 はそれらを `SCRIPT` に保存していたためです。

## 使い方

撮影モードで ADJ レバーを押し込んで ADJ モードにし、6 番目の項目 GRK を選びます。GRKit は電源を入れてから数秒後に読み込まれるため、この項目の表示が遅れることがあります。読み込みが終わると、撮影画面の上部に **GRKit** が数秒間表示されます。この表示にはフレーミングまたはグリッドのモジュールが必要です。

![GRKit のページに、モジュールの一覧と現在のエフェクトが表示されています。](images/grkit-root.jpg)

写真：nagi usano による [Snow in Akihabara](https://www.flickr.com/photos/cafetricot/51803682755/)、[CC BY 2.0](https://creativecommons.org/licenses/by/2.0/)。

- **イメージコントロール（Image Control）：** エフェクトにカーソルを合わせると、プレビューが表示されます。OK ボタンで確定します。Fn ボタンを押すと、そのエフェクトの［スタンダード］のパラメーターを調整できます。GRK メニューのイメージコントロールの行で Fn ボタンを押すと、選択中のエフェクトを調整できます。調整内容はエフェクトごとに保存され、カメラのイメージコントロールの設定は変わりません。
- **フレーミング（Framing）：** XPan、2.35:1、16:9、4:3、5:4、1:1 から選びます。1:1 はカメラの［アスペクト比］の 1:1 を使います。ほかの比率を選ぶと［アスペクト比］が 3:2 になり、撮影画面では写真の範囲外が暗く表示されます。DNG ファイルにはセンサー全体の画像が残り、切り抜き範囲が記録されます。記録された切り抜き範囲を適用する RAW 現像ソフトでは、写真の範囲だけが表示されます。
- **グリッド（Guides）：** グリッドの種類を選びます。線は撮影画面にだけ表示されます。
- **日付入れ撮影（Date Imprint）：** OK ボタンを押すと設定が開きます。**日付のスタイル（Date Style）** で日付のスタイルを選びます。**日付の書体（Date Look）** で数字の書体を選びます：クラシック、GR1s、GR II。写真の右下に日付が入ります。
- **粒状感（Grain）：** 弱、中、強から選びます。粒状感が加わるのは写真だけです。

最後の行の GRK にカーソルを合わせると、GRKit のバージョンが表示されます。

MENU ボタンを押すと、1 つ前の階層に戻ります。GRKit の設定は電源を切っても保持されます。

GRKit はエフェクトをカードの `GRKIT/EFFECTS` フォルダーに保存します。新しいパッケージは、そのエフェクトを追加し、以前のバージョンを置き換えます。ほかのエフェクトは削除しません。エフェクトを削除するには、カメラの電源を切り、`GRKIT/EFFECTS` からそのファイルを削除します。後のパッケージでそのファイルが変わったときだけ、再び追加されます。`GRKIT/EFFECTS.TXT` に各エフェクトのファイルが載っています。GRKit がインストールするエフェクトは 20 個までです。最後にコピーしたパッケージのエフェクトが優先されます。

## トラブルシューティング

### MENU ボタンを押したまま電源を入れると、ファームウェアの更新が始まる

カードのルートにファームウェアの更新ファイルがあります。カメラの電源を切ります。カードのルートから `.bin` ファイルをすべて削除します。その後、手順 3 をやり直します。

### Mode Set Command が表示されない

- MENU ボタンを押したまま電源を入れます。電源を入れた後に MENU ボタンを押しても、SD スクリプトはオンになりません。
- `SD_ROOT` の中身は、`DCIM` などのフォルダーではなく、カードのルートにコピーします。

### ADJ モードに GRK が表示されない

1. 電源を入れてから数秒待ちます。GRKit はカメラの起動後に読み込まれます。読み込みが終わると、撮影画面の上部に **GRKit** が数秒間表示されます。
2. GRK は ADJ モードにあります。MENU にはありません。
3. 手順 3 で Mode Set Command が表示されなかった場合は、手順 3 をやり直します。
4. カードのルートに `SCRIPT` フォルダーがあることを確認します。`SCRIPT` を含めて、`SD_ROOT` の中身をすべてコピーします。
5. カードに `SCRIPT/PLUGINS/INSTALL.ERR` がある場合、GRKit はインストールされていません。パッケージがカメラのファームウェアのバージョンに合っていることを確認します。ファームウェアのバージョンは、カメラのメニューで確認できます。バージョンが合っている場合は、`INSTALL.ERR` の内容をすべて添えて[デバイスレポート](https://github.com/ahonn/grkit/issues/new?template=device-report.yml)を送ってください。
6. GRKit は Ricoh の公式ファームウェアでのみ動作します。改造されたファームウェアでは動作しません。

## 削除と復旧

GRKit を削除するには、カメラの電源を切ります。次に、カードから `SCRIPT` フォルダーと `GRKIT` フォルダーを削除します。`GRKIT` には GRKit の設定が入っています。

SD スクリプトの設定はオンのままです。オフにするには：

1. https://grkit.app で、お使いのカメラの SD スクリプトをオフにするファイルをダウンロードします。ボタンはインストール手順の下にあります。
2. `SD_ROOT` の中身をカードのルートにコピーします。
3. カードを入れます。MENU ボタンを押したまま電源を入れ、電源が自動で切れるまで待ちます。
4. カードのルートから `00078350.588` と `DEVELOP.MOD` を削除します。

起動の途中でカメラが止まった場合は、バッテリーとカードを取り出します。次に、カードを入れずにカメラを起動します。それでも起動しない場合は、[復旧ガイド](https://github.com/ahonn/grkit/blob/main/resources/RECOVERY.ja.md)を参照してください。
