# GRKit

仅适用于 RICOH GR IV 和 GR IV HDF 固件 1.11。
一个包适用于每个受支持的固件版本。每次开机时，GRKit 会识别相机的固件。
固件 1.20（GR IV Monochrome 上为 1.10）的更新无法撤销。更新后，同一个包仍然可以使用。
GR IV Monochrome 运行 GR IV 的固件，但显示自己的版本号：固件 1.11 显示为 1.00，固件 1.20 显示为 1.10。它的包不含影像控制。GR IV Monochrome 使用 GR IV 的运行时，但本身未经真机测试。

## 安装

1. 关闭相机。
2. 把 `SD_ROOT` 中的内容复制到存储卡根目录。
3. 插入存储卡。按住 MENU 按钮开机。等待相机自动关机。
4. 正常开机。

第 3 步会打开相机的 SD 脚本功能。相机先显示 Mode Set Command，然后显示 Complete，之后自动关机。

![Mode Set Command 画面显示 Script - Enable 和 Complete。](images/modeset.png)

如果 SD 脚本功能已经打开，跳过第 3 步。
安装完成后，你可以从存储卡根目录删除 `00078560.636` 和 `DEVELOP.MOD`。这一步是可选的。

## 更新

1. 关闭相机。
2. 把新安装包中 `SD_ROOT` 的内容复制到存储卡根目录。替换或合并已有文件都可以。
3. 正常开机。

GRKit 把设置和效果保存在 `GRKIT` 文件夹中，所以更新后它们仍在。不需要先删除 `SCRIPT`。如果从 GRKit 1.2 或更早版本更新，并替换了 `SCRIPT` 文件夹（例如使用 macOS 访达默认的“替换”），之前的设置，以及新安装包中没有的效果，会丢失，因为 GRKit 1.2 把它们保存在 `SCRIPT` 中。

## 使用

在拍摄模式下按下 ADJ 杆进入 ADJ 模式，然后选择第 6 个功能 GRK。GRKit 在开机几秒后才加载，所以 GRK 可能稍后才出现。加载完成后，拍摄画面顶部会显示 **GRKit** 几秒。这个提示需要画幅或辅助线模块。

- **影像控制（Image Control）：** 高亮一个效果，即可在实时显示中预览。按 OK 按钮保留这个效果。按 Fn 按钮调整这个效果的 [标准] 参数。在 GRK 菜单的影像控制一行按 Fn 按钮，可以调整当前选择的效果。每个效果单独保存自己的调整，不会改变相机的影像控制设置。这些效果是为 GR III 制作的，所以在 GR IV 上颜色可能不同。
- **画幅（Framing）：** 选择 XPan、2.35:1、16:9、4:3、5:4 或 1:1。16:9、4:3 和 1:1 使用相机自带的 [长宽比]。XPan、2.35:1 和 5:4 会把相机的 [长宽比] 设为 3:2，显示屏仍按 3:2 显示，照片以外的区域会变暗。相机的 [长宽比] 设为 16:9 时也可以使用 XPan 和 2.35:1。DNG 文件保留完整的传感器图像，并记录裁切范围。应用这个裁切范围的 RAW 软件只显示照片区域。
- **辅助线（Guides）：** 选择一种辅助线样式。辅助线只显示在显示屏上，不会出现在照片中。
- **加印日期摄影（Date Imprint）：** 按 OK 按钮打开设置。在 **日期样式（Date Style）** 中选择一种日期样式。在 **日期字体（Date Look）** 中选择数字的字体：经典、GR1s 或 GR II。照片右下角会加印日期。
- **颗粒感（Grain）：** 选择弱、中或强。颗粒感只加在照片上，不影响影片。

高亮最后一行 GRK，即可看到 GRKit 的版本号。

按 MENU 按钮返回上一级。关机后 GRKit 会保留你的设定。

GRKit 把效果保存在存储卡的 `GRKIT/EFFECTS` 文件夹中。新的安装包会加入它的效果，并替换这些效果的旧版本，但不会移除其他效果。要移除一个效果，先关闭相机，然后从 `GRKIT/EFFECTS` 删除它的文件。只有当之后的安装包中这个效果的文件有变化时，它才会被重新加入。`GRKIT/EFFECTS.TXT` 列出每个效果的文件。GRKit 最多安装 20 个效果：先安装最近一个安装包的效果，再安装其他效果。

## 故障排除

### 按住 MENU 按钮开机时，相机开始更新固件

存储卡根目录中有固件更新文件。关闭相机。从存储卡根目录删除所有 `.bin` 文件。然后重新执行第 3 步。

### 相机没有显示 Mode Set Command

- 先按住 MENU 按钮，再开机。如果开机后才按 MENU 按钮，SD 脚本功能不会打开。
- 把 `SD_ROOT` 中的内容复制到存储卡根目录，不要复制到 `DCIM` 或其他文件夹中。

### ADJ 模式中没有 GRK

1. 开机后等待几秒。GRKit 在相机启动后才加载。加载完成后，拍摄画面顶部会显示 **GRKit** 几秒。
2. 在 ADJ 模式中找 GRK。GRK 不在 MENU 菜单中。
3. 如果第 3 步中相机没有显示 Mode Set Command，重新执行第 3 步。
4. 确认存储卡根目录中有 `SCRIPT` 文件夹。复制 `SD_ROOT` 中的全部内容，包括 `SCRIPT`。
5. 如果存储卡中有 `SCRIPT/PLUGINS/INSTALL.ERR`，表示 GRKit 没有安装成功。确认相机显示的是受支持的固件版本。在相机菜单中可以查看固件版本。如果版本受支持，请提交[设备报告](https://github.com/ahonn/grkit/issues/new?template=device-report.yml)，并附上 `INSTALL.ERR` 中的全部内容。
6. GRKit 只能在 Ricoh 官方固件上运行，不能在修改过的固件上运行。

## 移除或恢复

要移除 GRKit，先关闭相机。然后从存储卡删除 `SCRIPT` 和 `GRKIT` 文件夹。`GRKIT` 保存 GRKit 的设置。

SD 脚本设置会保持打开。要关闭它：

1. 在 https://grkit.app 下载你的相机对应的关闭 SD 脚本的文件。按钮在安装步骤下方。
2. 把 `SD_ROOT` 中的内容复制到存储卡根目录。
3. 插入存储卡。按住 MENU 按钮开机，等待相机自动关机。
4. 从存储卡根目录删除 `00078560.636` 和 `DEVELOP.MOD`。

如果相机在启动时停止响应，取出电池和存储卡。然后不插存储卡开机。如果仍然无法启动，请参阅[恢复指南](https://github.com/ahonn/grkit/blob/main/resources/RECOVERY.zh-Hans.md)。

GRKit 与 Ricoh 无关。源代码和许可：https://github.com/ahonn/grkit
